# icons/

Small square marks: favicons, app icons, social avatars, and any UI glyph that needs to
read clearly at 16–64 px.

Square aspect ratio, minimal detail, tested at 16 px. Ship an SVG plus a 512 px PNG.
Favicons additionally need a multi-resolution `.ico`.
