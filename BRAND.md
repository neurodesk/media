# Using the Neurodesk marks

> **The [Neurodesk Designer Guide](https://neurodesk.org/developers/designer/) is the
> canonical source for visual standards** — colour palette, typography, capitalization,
> and usage examples. This file does not duplicate it. It covers only what the guide
> doesn't: the licensing status of these files, and which file to grab for which job.

## Licensing status

This is the part the Designer Guide doesn't state, and it matters:

| What | Terms |
|---|---|
| Figures, diagrams, screenshots in this repo | [CC-BY-4.0](LICENSE) — reuse freely with attribution |
| The Neurodesk **name and logo** | Project marks — **not** CC-BY, see below |

### You may, without asking

- Use an unmodified logo to link to [neurodesk.org](https://neurodesk.org) or a Neurodesk repo.
- Use an unmodified logo in slides, posters, papers, or blog posts that describe, teach,
  review, or cite Neurodesk.
- State truthfully that your tool, pipeline, or course uses or supports Neurodesk.
- Scale proportionally, and pick whichever variant reads best on your background.

### Please ask first

Open an issue here, or email <mail.neurodesk@gmail.com>, before you:

- Change the logo's colours, proportions, typography, or artwork.
- Combine it with another mark into a new lockup.
- Use it on merchandise, event branding, or in a domain name.
- Use it in a way that could imply Neurodesk endorses or certifies your product.

Neurodesk is a community project and generally says yes — asking is mostly so we know.

## Which file do I want?

| Context | Variant |
|---|---|
| Light or neutral background | the standard variant |
| Dark background | the `-on-dark` variant |
| Wide header, one line of space | the `-horizontal` variant |
| You want the web address visible | the `neurodesk-org-` prefix |
| Pride / inclusivity contexts | the `-pride` variant |

See [logo/README.md](logo/README.md) for the full inventory.

## Colour

The authoritative palette lives in the
[Designer Guide](https://neurodesk.org/developers/designer/#color-palette). Primary is
**Seafoam green `#6aa329`**. The Illustrator swatch file is in [`palette/`](palette/).

Do not read colours off a rendered logo — anti-aliasing and the site's inline SVG both
give slightly different values than the documented palette.

## Naming and capitalization

Covered in the
[Designer Guide](https://neurodesk.org/developers/designer/#naming-and-capitalization-guidelines).
Short version: **Neurodesk**, **Neurodesktop**, **Neurocommand**, **Neurocontainers**,
**NeurodeskApp**. Never `neuroDesk`.

## Typography

Covered in the [Designer Guide](https://neurodesk.org/developers/designer/#typography).
Logo font is [Scirich](https://github.com/micmas/Scirich-font); headings and body are
Pontano; code is Menlo.
